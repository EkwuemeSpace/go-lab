# Palindrome Checker CLI

A simple command-line application written in Go that checks whether a word, number, or sentence is a palindrome.

## Features

- Supports words, numbers, and sentences
- Ignores spaces and letter casing
- Validates user input
- Interactive CLI experience
- Exit option for terminating the application

## Example

Input:
A man a plan a canal Panama

Output:
true palindrome
